Row lock/skip-locked claim commits PUBLISHING + lease before network I/O, publish confirmed persistent message with stable task_id. Token-conditional writeback avoids regressions if Worker already reached PROCESSING/SUCCEEDED.
3. On PUBLISHING expiry, message may have been sent: retry publication, never infer absence from stale status. PUBLISHED means confirmed by broker, not business success; claim deadline triggers bounded republish if no execution claim.
