日期：2026-10-05。仅覆盖本轮短信认证与正常新用户准入；不重做 0015、WO20。所有手机号、验证码和凭据均为隔离测试内的合成值，不进入本报告。

## 源码与隔离

- 根构建上下文下，`deploy/.env.delivery` 曾可被 Docker bind-mount 探针读取；加入定向 `.dockerignore` 规则后，同一无网络、无镜像产出的探针返回 `not found`。规则与边界详见 `preflight.md`。
- 生产短信 Provider 使用官方 PNVS SDK 2.0.0、显式 HTTPS、`AutoRetry=0`、SDK `autoretry=False` 与 `max_attempts=1`；三种用途分别取登录、重置密码和换绑模板。SDK 错误不回退 Development。明确带有效服务端请求号的 4xx 与业务拒绝计次后结束本次占用；超时、无响应、畸形响应、缺失/占位请求号保持 `IN_FLIGHT` 并暂停后续发送。
- 发送前使用固定非过期 Redis 键原子占用 1 次/75 毫元，最多 4 次/300 毫元。一次性启用要求 AOF `appendonly=yes` 且 `appendfsync=always`。运营商未明确接受前，验证码在 MySQL 中以不可核验状态保存；仅精确匹配本次 ID 且仍为最新请求时激活。
- 阿里云[官方模板清单](https://help.aliyun.com/zh/pnvs/user-guide/sms-authentication-service/)将登录/注册、重置密码、修改绑定手机号对应到 `100001`、`100003`、`100002`；本轮首次设密与忘记密码共用现有 `reset` 用途及重置密码模板。是否能使用这些模板仍以本机账号控制台实际签名/模板配对为准。官方[API 版价格公告](https://help.aliyun.com/zh/pnvs/product-overview/price-and-package-deduction-method-adjustment-notice)显示首档按量 0.06 元/次；本地按 0.075 元/尝试保守占额，不把它冒称为已发生费用。
