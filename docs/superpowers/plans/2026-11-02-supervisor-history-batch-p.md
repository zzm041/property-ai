# T10：主管查看已有协调记录

现有主管队列可提交决定，但不展示该工单历史说明；仅员工页展示不足以支持主管接续人工联系。复用workOrder(id, property)和现有日志/extra_notes，在所选工单提供只读“查看内部记录”。不新增表、写接口或自动调度，也不改变评分/容量。

逐次由后端鉴权，返回id/property_id/version必须与当前选择一致；选择、刷新、切换小区、隐藏、卸载和业务动作清除旧内容并使旧请求失效。显示既有主管reason及累计处理说明；累计说明不标成逐条带时间的履历，日志操作人不冒充实际维修人。

合成Node验证匹配、过期版本、越小区结果、权限错误、隐藏/选择后旧响应；相邻主管诊断、audience和布局检查，独立只读复审。原生页面与运行仍另验。
