# T04：公告管理角色与范围必须来自同一授权

承接已授权的物业连续实施。独立只读审查复现：用户在目标小区是OWNER住户，但在其他小区/租户为SUPERVISOR时，list_published将目标公告audience扩大为STAFF等内部范围。根因是全局roles与目标read权限来自不同grant。

只修改announcement.py的manager_read判定：同一grant同时具备管理role、ANNOUNCEMENT_READ和允许目标scope。保留现有有效住户、员工关系及本范围管理行为，不新建权限体系。补同租户不同小区/跨租户、拆散权限、合法物业/租户管理、普通住户对照。先红后绿，复审实际差异；不涉及模型、数据库或服务。

这修复跨范围授权拼接；公告显式住户/物业用途及历史个人通知保留是后续不同问题，不据本批关闭整个T04。新公告内容不外传，测试仅合成。
