# V：媒体模型部署版本与检查点

延续 T06b，仅补 ASR/VLM Provider 已有复用契约的版本缺口。当前模型名、端点、提示词/协议已入指纹，但同名换权重不可识别。新增可选 VLM_MODEL_REVISION / ASR_MODEL_REVISION（不超过128字符的制品版本标签），由部署者填实际权重哈希或不可变发布号。实际模型请求仍用原 model 别名。

指定 revision 时进入 checkpoint_fingerprint；同版本复用、换版本拒绝旧单文件与聚合检查点。未指定时严格保持原指纹以保护现有有效证据，不宣称空值可防范同名替换；不能自动探测或证明服务端实际权重。轮换密钥和网络超时设置不影响语义指纹。

不修改已完成分析、历史工单、全局输入哈希、LLM完整分析复用策略或真实服务配置；不触发重分析。上线切换前须盘点仍在重试的媒体任务及新增推理成本，只处理具名批准范围；完成任务不重放。

范围：core/config.py、provider/factory.py、provider/asr及vision、部署文档、专项测试与检查入口。没有迁移、依赖升级或模型启动。先反例、再小步实现，相关Provider/配置/媒体回归，最后独立只读复审。真实部署版本核实与成本盘点仍属于后续运行工作，不能由合成测试替代。
