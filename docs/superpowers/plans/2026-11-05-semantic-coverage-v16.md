## 契约与成对案例

| label | 接受的可观察事实 | 不得混同 |
|---|---|---|
| 闭合失效（新增） | 门/窗合不上、关不齐、锁扣扣不住 | 操作费力、内部锁芯损坏、已经关闭 |
| 排水缓慢（新增） | 排水慢、下水不利索、水很久才下去 | 完全堵死、供水不足、管道原因已确诊 |
| 部件下垂（新增） | 柜门或构件下垂 | 松动、即将坠落 |
| 人员行为观察（新增） | 人员徘徊、张望、拉动车辆 | 犯罪成立、身份确定、车辆已失窃 |
| 操作阻力（扩展表达） | 卡住、拉不动、收不回 | 闭合失败原因、正常停在半程 |
| 杂物清扫（扩展表达） | 食物残渣、饭粒等待清理物 | 责任人身份、恶意破坏 |
| 照明不亮（扩展表达） | 灯还是黑的 | 全屋停电、黑色灯具外观 |

新增主体窗户、柜门、排水区域、人员，只接受对应当前分句的明确依据；原主体枚举继续读取。排水缓慢不得仅因“下水/排水”而填具体排水接头，需要明确接头证据，否则选区域或未知。人员行为不改变既有 security/security 规则，身份未知不能消灭明确行为。

## 重点风险

否定词可能是现象的一部分；历史后接当前重现不可混淆；位置不能变成具体部件；未知身份不能否定当前行为；同句多对象不能相互借用。每项必须有成对测试。词表是有限守卫，不宣称任意自然语言语义正确，未见样本仍需真实模型验证。

保持原 evt2 算法和旧标签身份；新增标签以自身名称进入身份集合，与旧不等价现象不同键。提示词升级使新输入指纹隔离。已保存记录不自动重分析。真实模型、共享服务、费用等仍按具名授权执行。

复审裁定：人员行为观察是宽标签，其新事件身份必须包含该条证据原文，不能让徘徊、张望与拉动车辆共用人员+标签键。该新标签专用规则不改旧键。新请求的v16指纹与v15隔离，但已完成历史 prior_claim 继续复用，不自动重分析。主体的既有宽别名需分阶段收紧：本次排水缓慢严格要求接头原词；旧滴漏兼容不能未经证据核对全局改写，后续用成对案例审查其映射，不声称旧宽别名已全部解决。
