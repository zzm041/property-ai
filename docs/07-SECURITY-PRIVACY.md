# 07 — 安全与隐私

## 1. 威胁模型（V1 必须防）

- 越权访问其他小区工单 / 住户手机号
- 验证码被刷导致短信轰炸
- 弱口令与撞库
- 上传恶意文件
- 日志泄漏身份证、验证码、Token
- 知识库跨小区召回
- 账号抢绑（用别人手机号、别人微信）
- 派单接口被普通员工改派给自己刷单

## 2. 身份安全

- 密码：强哈希（Argon2id 优先，bcrypt 可作兼容）。禁止明文、禁止可逆加密。
- 验证码：只存哈希、短 TTL、尝试次数上限、图形/行为频控 + 每号每小时上限。
- 登录失败策略（2026-09-23负责人明确调整“不锁定”）：不新增手机号/IP累计失败锁定；错误凭证仍拒绝，保留验证码挑战、单验证码尝试上限、发送频控和现有总请求限流。原锁定要求作为历史需求保留，不把政策调整写成测试通过；生产防滥用和安全验收仍须完成。
- Token：短效 access + 可旋转 refresh；登出作废。
- 换手机 / 换微信 / 合并 / 恢复：二次验证 + AuditLog。
- 高风险恢复：第三方实名 + 活体。本系统 **禁止** 存原始人脸图用于比对，禁止自建人脸特征库。若 Provider 回传照片，只作审核工单的短期对象存储并设 TTL，不进入向量库。

## 3. 数据分级与脱敏

| 级别 | 例子 | 存储 | 日志 |
| --- | --- | --- | --- |
| L1 公开 | 小区名、已发布公告 | 明文 | 明文 |
| L2 内部 | 工单摘要、员工姓名 | 明文 | 明文 |
| L3 个人 | 手机号、房号+姓名 | 明文+访问控制 | 脱敏 `138****1234` |
| L4 敏感 | 身份证号 | 字段加密 | 禁止 |
| L5 禁止落库 | 人脸特征、验证码明文、密码明文 | 不存 | 不存 |

管理后台默认展示脱敏值，显式“查看明文”再记审计。

## 4. 租户隔离

- 每个查询在 repository 层强制 `tenant_id`（及需要时 `property_id`）。
- 禁止把隔离过滤只写在前端。
- 客户端提交的 tenant/property 只是请求上下文，不是权限事实；授权必须由认证用户、角色 Scope、目标资源与数据库关系共同决定。
- 核心表使用顺序 BIGINT ID，安全不能依赖 ID 不可猜。每个按 ID 访问资源的路径都必须覆盖 Cross Tenant、Cross Property 与 IDOR 测试。
- 组织 Scope 仅 `SYSTEM / TENANT / PROPERTY`；SELF 类访问通过资源所有权或有效关系判断。
- 系统管理员默认看元数据；看业务明文需单独权限。

## 5. 文件上传

- 类型白名单、大小、魔数、随机存储名、不可执行目录。
- 访问通过鉴权 URL 或带过期签名，不暴露可枚举的连续 ID 文件路径。

## 6. 密钥管理

- 所有 Secret 来自环境变量或部署侧 secret 文件。
- `.env` 不入库。`.env.example` 只有空值和假数据。
- 不同环境不同 `APP_SECRET_KEY`。

## 6.1 Development 能力保护

- Development Auth 与 Dev Seed 仅允许 `APP_ENV=development` 或 `test`。
- `APP_ENV=production` 且开启 Development Auth 时必须在启动或调用前触发安全保护并拒绝运行。
- production 必须拒绝 Dev Seed；企业初始化未来走独立 Import / Admin Operation / Production Bootstrap。
- Development Auth 的角色和 Scope 从真实数据库读取，客户端不得通过提交角色名获得权限，也不得绕过 RBAC 或租户隔离。

## 7. 并发与幂等

- 创建工单、发送短信、接单、发布公告、账号合并必须幂等或条件更新。
- 使用 `Idempotency-Key` 表防重复提交。
- 派单容量用 Redis 锁 + DB 校验，避免超卖负载。

## 8. 合规注意（实现约束）

- 人脸与身份证核验走具备资质的第三方 Provider（生产）。
- 开发环境永远走 Development Provider。
- 备份文件与数据库转储按敏感级加密；恢复演练不使用真实业主全量拷到个人电脑。

## 9. 安全开发检查（每个模块）

- [ ] 未授权 / 错误范围返回 401/403
- [ ] 跨小区 IDOR 测试
- [ ] 跨 Tenant、跨 Property 与篡改 `property_id` 测试
- [ ] 错误信息无栈、无 SQL
- [ ] 速率限制
- [ ] 审计字段齐全
