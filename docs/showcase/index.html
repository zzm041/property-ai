三个必须成立的约束

模型不许编

分析结果按固定 schema 校验：类别、子类、严重度、优先级、摘要、风险、所需角色、所需技能、置信度，缺一个或越界即判失败，不落库。

app/domain/observed_event.py

同一单不重复叫人

派单有 600 秒冷却：被拒或超时的单在窗口内不会再次派给同一个人，避免反复打扰。

app/service/dispatch.py

事务在服务层

状态流转、幂等键、租户与小区校验都在 Service 完成，路由只做参数转换，测试可以直接打服务层。

app/service/work_order.py

系统由这些部分组成

微信原生小程序住户 · 维修人员 · 物业主管
FastAPI 业务服务身份权限 · 工单状态 · 规则派单
Celery Worker报修分析 · 知识处理 · 失败重试
本地模型服务Qwen 27B · 语音 · 向量 · 重排，经 Provider 接入

MySQL 存业务数据，Redis 提供缓存与锁，RabbitMQ 承载异步任务，Milvus 支撑知识检索；十一个容器由 Docker Compose 编排，Nginx 统一入口。
