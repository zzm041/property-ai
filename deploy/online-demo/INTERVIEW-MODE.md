# 私密面试交互演示

用途：受邀面试官通过浏览器亲自操作报修与真实AI；由项目持有人在面试前开启、结束后关闭。不是大众体验服务，也不是只读回放或以屏幕共享替代交互。

## 访问与资源边界

- 默认仅本机可访问。控制器的`remote_access`默认为false，不调用Tailscale转发。只有审核了配置并明确开启远程模式，才尝试建立HTTPS入口。
- 演示链接与随机邀请口令私下发送，不放在GitHub README、网页源码、公开日志或公开简历。GitHub介绍写“可预约现场交互演示”，另附明确标注为录制内容的演示材料。
- 口令只能兑换一个会话。刷新保留原会话；丢失cookie后不能用同一口令重领。会话凭证即使被复制，仍共享同一工单和模型总额度，不产生新额度。结束后全部失效。
- 当前首轮验收最多一张合成工单、三次模型入口尝试、30分钟、并发1。失败和未知结果占额，不自动重报。访客不能修改这些限制，不能重启窗口或追加次数。
- 模型端口、后端完整API、管理界面、数据库与文件目录不作为远程转发目标。唯一可转发的是只包含邀请登录、限定报修及脱敏进度的浏览器适配入口。
- “链接私下发送”不是唯一防护：服务端验证邀请、请求来源、字段范围、主体权限、调用总额、时间和资源。临时HTTPS地址从网络上仍可能被访问；未授权请求不能触发模型。不能宣称绝对没有网络攻击风险。

## 控制器与退出

`scripts.online_window`只接管另行准备的独立合成环境，不创建真实资料，不重启现有v26，不修改Tailscale登录/策略，不自动启用开机转发。

配置示例见`controller.example.json`，占位值故意不能执行。实际清单必须绑定源码摘要、两份私密配置摘要、完整独立容器ID与镜像摘要。默认运行只显示准备清单；传入核对过的配置SHA才执行。

```text
python -m scripts.online_window --config <私密控制器配置>
python -m scripts.online_window --config <私密控制器配置> --approve-config <核对的SHA256>
```

首次实际GPU/远程执行仍需单独批准；目前仅源码与模拟控制检查通过。面试官不需要安装Tailscale，持有人电脑需要安装并登录；操作系统网络入口仍须按现场状态验证。

控制器核对容器/网络/卷归属、后台回环端口及所有模型地址/令牌，先核对监听PID属于本轮Windows Job，再发送认证探针或建立转发。前台关闭用Ctrl+C。到期或资源不足终止本轮Job，并停止所列独立演示容器；保留卷和证据，不删除数据、不按进程名批量停止。

结束时检查本轮进程数为0、监听已关闭、Funnel状态为空、所属容器已停止。有一项无法确认即记录CLOSED_WITH_ERRORS；CLOSED_CLEAN只说明关闭核对完成，不表示业务/AI演示通过。启动失败仍单独记录execution_error并返回非零退出码。

Tailscale目前只完成安装登录核对，未开启Funnel；HTTPS账号设置与实际异网连通仍未验证。客户正式部署不依赖Tailscale，此选项仅服务持有人的面试演示。
