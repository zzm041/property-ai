# 浏览器真实 AI 体验入口

当前用途为[私密面试交互演示](INTERVIEW-MODE.md)：面试官亲自操作，持有人手动开关；默认不开放远程，地址和一次性口令不公开到GitHub。不是大众试用，也不改为只读回放。口令只兑换一个会话，所有请求共享本场额度。

状态：已完成源码、隔离 HTTP 合约与桌面/手机浏览器显示检查，尚未连接实际演示后端，也未开放公网。检查中的模拟响应仅用于验证界面，不是实际 AI 体验的结果。

生产客户端仍为微信原生小程序。此适配入口复用后端的报修与查询 API，浏览器只提交三个固定合成场景之一；分类、分析和派单结果从业务后端读取，没有模拟推理分支。每个具名窗口最多接收一张新工单。新增窗口和 GPU/公网使用须按运营安排单独启动，不能复用历史已关闭窗口。

## 私密配置与隔离约束

- 将 `runtime.example.json` 复制至仓库外的私密运行目录。示例到期时间与身份 ID 故意无效，必须绑定实际独立合成环境。
- `backend_url` 为私网数字 IP 的 HTTP 地址，不允许 URL 账户、重定向或环境代理；当前本地 8080/8093 入口禁止使用。不能指向现有 v26。
- `window_id` 由小写字母、数字、短横线组成，长度3–40。上游必须是 staging，队列为 `property_ai.online_demo.<window_id>`，死信队列加 `.dlq`；bucket为 `online-demo-<window_id>`；索引名为 `online_demo_<window_id将短横线改下划线>`。存储和 LLM Provider 均为 production。
- 启动时只用 operator Token 读取 `/api/v1/opsz`，成功后不再保留它用于访客请求。报修与查看只使用独立合成住户的 resident Token；正常业务 API 的 RBAC/所有权判断仍有效。
- 两个 Token 文件是运维预先通过正常认证取得的会话凭证，不在网页登录，也不向浏览器返回。应覆盖本次窗口有效期，过期时明确失败，不绕过认证。所有私密文件仅允许运维账户读取，不提交 Git。体验口令文件为随机32–128位 URL-safe ASCII，提供给本轮访问者。
- 配置的 tenant/property/house/reporter 四个 ID 必须全部来自隔离的合成对象。每次上游创建/查询返回均再次核对身份。固定联系号码只作为合成字段，不执行电话或短信。
- `expires_at` 为绝对 Unix 秒，启动时距到期最多30分钟；`origin` 是唯一公开 HTTPS 来源，本机页面检查可用 `http://127.0.0.1:<port>`。不要将业务或模型端口直接暴露出去。

`opsz` 命名核对只证明逻辑命名，不证明数据库/卷独占或模型已可用；部署控制器必须另行核对实际数据库、网络、卷、镜像、凭证隔离和 GPU 归属。

## 运行与限制

在独立环境、模型总额度和公网关闭控制器准备并获准后，从项目根目录使用已安装后端依赖的 Python：

```text
python -m scripts.online_demo --config <private-runtime.json> --port 18094
```

仅监听 127.0.0.1，单进程，无 reload。到期拒绝动态操作；访问者可看到关闭提示。窗口记录文件以独占创建方式生成，存在则拒绝重启；不要删除记录来恢复额度。手动结束使用前台 Ctrl+C，控制器负责更完整的服务关闭。

创建请求先写入并落盘预留记录，再调用后端；结果不明确、超时或中断都不退回额度、不自动重发。刷新只读取本会话工单；不能输入其他工单号。显示字段排除电话、姓名、原始日志与其他访客资料。低置信度、过期分析、人工安排、无当前自动分配与已完成/撤销工单分别显示，不把它们标成自动派单成功。

本入口限制的是新工单数，**不等于模型调用次数**。一个工单可能触发后端重试；私有模型入口支持`--window`的持久总尝试预算及到期取消，见[自托管入口](../selfhost/README.md)。Windows整窗控制器源码已整合进程归属、可选受邀远程入口和独立容器关闭，尚未完成实际整窗验证，不应单独将此网页进程接入公网。
